# Global Sales Performance Dashboard

## Project Overview

This project is an interactive **Global Sales Performance Dashboard** developed using Microsoft Power BI.

The purpose of this dashboard is to analyze sales performance, monitor key business metrics, and explore customer behavior, product performance, and regional sales.

## Business Questions

This dashboard helps answer the following business questions:

- What is the total revenue?
- How many orders and customers does the business have?
- What is the average order value (AOV)?
- How many returning customers are there?
- Which product categories and sub-categories generate the most revenue?
- Which countries and regions contribute the most to sales?
- Which products generate the highest revenue?
- How is profit status distributed?

## Key Performance Indicators (KPIs)

- Total Revenue
- Average Order Value (AOV)
- Total Orders
- Total Customers
- Returning Customers

## Dashboard Features

- Revenue analysis by category and sub-category
- Sales performance by country and region
- Top 10 products by revenue
- Profit status distribution
- Interactive filters for Category, Country, and Year
- KPI cards for monitoring overall business performance

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Challenges & Learning

During the development of this project, I faced several practical challenges:

- **Data Preparation:** Investigating inconsistencies in date fields during data preparation and merge operations.
- **Data Quality:** Identifying blank and missing values and understanding their impact on analysis.
- **Data Modeling:** Understanding table relationships and date fields to support reliable reporting.
- **DAX Measures:** Developing measures for business KPIs such as Total Revenue, Average Order Value, and Returning Customers.
- **Dashboard Design:** Improving layout, visual hierarchy, formatting, and consistency.
- **Interactive Analysis:** Implementing slicers to explore sales performance across different business dimensions.

Working through these challenges improved my practical understanding of Power BI, data preparation, data modeling, and business-focused data visualization.
